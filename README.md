# fatihozturk.net

Fatih Öztürk'ün kişisel sitesi — saf HTML/CSS/JS, derleme adımı yok.

- `index.html` — içerik (Türkçe, varsayılan dil)
- `i18n.js` — İngilizce çeviriler (`data-i18n` anahtarlarıyla eşleşir)
- `style.css` — tasarım, `main.js` — etkileşimler
- `assets/` — CV'ler, favicon

Yerelde çalıştırmak için: `python -m http.server 5173`
